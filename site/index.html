    Why PulsarScript

    Predictable like a spec. Contained like a kernel.

    Engineered specifically for embedding third-party PulsarOS app logic where untrusted scripts share host resources with real users.

    RPC Handlers

    Sub-microsecond Dispatch

    Expose registerHandler(name, fn) entrypoints from app bundles. Hot dispatch runs in 201.3 ns with 0 heap allocations inside a 250,000-step / 1.5 s cage.

    Background Services

    Event-Driven Watchers

    Long-lived workers subscribe via on(event, fn) and suspend without polling using yield, sleep, and async ErrSuspended host calls.

    Go Host VM

    Capability-Gated I/O

    No filesystem, KV, window channel, or IPC socket exists by default. Hosts inject only the capabilities declared by the app manifest and check every call.

    Compiler & VM Pipeline

    Four gates between source text and execution.

    Unknown functions, circular imports, invalid opcodes, stale SHA-256 bundles, and runaway allocations fail loudly before touching user data.

    1. 01 · LINK & PARSE

      Relative Modules

      Linker.ts resolves import/export graphs into one flat AST, rejecting circular imports at compile time.

    2. 02 · ANALYZE

      Static Checks

      Validates scoping, arity against hostapi.json, duplicate declarations, and unreachable code with line/column diagnostics.

    3. 03 · VERIFY

      Bytecode v3 + Hash

      Emits portable JSON bytecode (52 opcodes, loads v0–v3) with a SHA-256 sourceHash. Go VerifyModule rejects malformed chunks before execution.

    4. 04 · ENFORCE

      CoW VM & Capabilities

      Copy-on-Write persistence preserves D15 value snapshots while budgets unwind uncatchably through try/catch.

    Deliberate Language Boundaries in SPEC v1.0

    Several C-family constructs are intentionally excluded by SPEC.md to keep the compiler, analyzer, and Go VM compact and unambiguous:

    • No ++ / --, switch, or do…while — use += 1, chained if/else or ternaries ?:, and while / for…of.
    • Only nil and false are falsy — 0 and "" are truthy under §3.1.
    • Every assignment has D15 value-snapshot semantics backed by CoW containers in the VM; shared state is mutated intentionally via variables or captured closure upvalues.
    Compatibility & Deprecation Policy (SPEC §10)

    The Go VM maintains backward load compatibility for versions N and N−1 (currently supporting Bytecode formats v0, v1, v2, and v3 simultaneously in vm.LoadModule), and enforces structured host-call metadata via vm/hostapi.json.
